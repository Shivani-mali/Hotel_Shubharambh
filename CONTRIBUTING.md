# Contributing to Hotel Shubharambh Website

First off, thank you for considering contributing to this project!

## How to Contribute

1. **Fork the Repository:** Create your own fork of the code.
2. **Clone:** Clone your fork to your local machine.
3. **Branch:** Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
4. **Develop:** Make your changes locally.
5. **Test:** Ensure the application builds without errors (`npm run build`).
6. **Commit:** Commit your changes with clear, descriptive commit messages.
7. **Push:** Push to your fork and submit a Pull Request to the main repository.

## Development Guidelines

- Ensure your code follows the existing style (Tailwind utility classes, React functional components).
- Do not modify or distribute the proprietary image assets without replacing them with placeholders.
- Always check that your components are mobile-responsive.
- Test your changes using `npm run dev`.
