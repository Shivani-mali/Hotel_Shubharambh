# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Comprehensive SEO infrastructure including `sitemap.xml`, `robots.txt`, and Open Graph tags.
- Full JSON-LD structured schemas for LocalBusiness and Restaurant.
- Enhanced Digital Menu Book component using `react-pageflip`.
- High-performance, lazy-loaded Masonry Gallery layout.
- Floating action buttons for WhatsApp and direct calling.

### Changed
- Rebuilt layout strictly following a Mobile-First approach.
- Updated main branding assets and optimized logo rendering.
- Refactored `index.css` to centralize Tailwind styling.

### Fixed
- Navigation overlapping on mobile devices.
- Image clipping issues across various breakpoints.
